== Installation ==

**🚀 Installation en 2 minutes :**

1. **Téléchargez** le plugin depuis le répertoire WordPress
2. **Activez** le plugin dans votre administration WordPress
3. **Allez dans** WooCommerce → Réglages → Paiements
4. **Activez** "UnitechPay" et cliquez sur "Gérer"
5. **Entrez** vos numéros Wave et Orange Money
6. **Sauvegardez** - C'est terminé !

**⚙️ Configuration détaillée :**

1. Dans l'admin WordPress, allez dans **Extensions → Extensions installées**
2. Trouvez "UnitechPay" et cliquez sur **"Activer"**
3. Naviguez vers **WooCommerce → Réglages → Paiements**
4. Activez la méthode de paiement **"UnitechPay"**
5. Cliquez sur **"Gérer"** pour configurer :
   - Votre numéro Wave (format : 7XXXXXXXX)
   - Votre numéro Orange Money (format : 7XXXXXXXX)
   - Vos frais supplémentaires (optionnel)
6. **Enregistrez** les modifications

**✅ Vérification :**
- Allez sur votre page de commande
- Vous devriez voir les options Wave et Orange Money
- Testez avec un petit montant

== Frequently Asked Questions ==

= Est-ce que j'ai besoin d'une API Wave ou Orange Money ? =

**Non !** C'est la beauté d'UnitechPay. Vous n'avez besoin d'aucune API complexe. Entrez simplement vos numéros Wave et Orange Money dans les paramètres du plugin, et tout fonctionne automatiquement.

= Comment l'argent arrive-t-il sur mon compte ? =

Dès qu'un client effectue un paiement, UnitechPay déduit automatiquement sa commission de 3% et transfère le reste directement sur votre numéro Wave ou Orange Money correspondant. C'est instantané !

= Y a-t-il des frais d'installation ou d'abonnement ? =

**Aucun !** Le plugin est complètement gratuit à télécharger et installer. Vous ne payez que 3% de commission sur les transactions réussies. Pas de frais mensuels, pas de frais cachés.

= Le plugin fonctionne-t-il avec tous les thèmes WordPress ? =

Oui ! UnitechPay est conçu pour être compatible avec tous les thèmes WordPress et WooCommerce. L'interface s'adapte automatiquement au design de votre site.

= Puis-je utiliser UnitechPay sur plusieurs sites ? =

Absolument ! Une fois installé, vous pouvez utiliser UnitechPay sur autant de sites que vous voulez. Chaque site peut avoir ses propres numéros Wave et Orange Money configurés.

= Que se passe-t-il si un paiement échoue ? =

Si un paiement échoue, la commande reste en statut "en attente" et aucune commission n'est prélevée. Le client peut réessayer le paiement ou choisir une autre méthode.

= Comment puis-je suivre mes transactions ? =

Toutes les transactions sont visibles dans votre administration WooCommerce. Vous pouvez voir les détails de chaque paiement, les commissions prélevées et les montants transférés.

= Le plugin est-il sécurisé ? =

Oui ! UnitechPay utilise des connexions HTTPS sécurisées et respecte les standards de sécurité WordPress et WooCommerce. Vos données et celles de vos clients sont protégées.
